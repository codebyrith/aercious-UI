## ⚡ Quick Start for Vercel Deployment

This project is pre-configured for **zero-configuration instant deployment on Vercel**.

### Option 1: Deploy via GitHub (Recommended)

1. Create a new repository on your GitHub account (e.g. `aercious-luxury-streetwear`).
2. Run the following commands in this directory:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/aercious-luxury-streetwear.git
   git branch -M main
   git push -u origin main
   ```
3. Go to [vercel.com/new](https://vercel.com/new) and click **Import** next to your GitHub repository.
4. Leave all build settings default (Framework: `Other`, Root Directory: `./`).
5. Click **Deploy**. Your luxury streetwear storefront will be live on `https://your-project.vercel.app` in under 30 seconds!

### Option 2: Deploy directly via Vercel CLI

```bash
npx vercel
```
Follow the interactive prompts to link your Vercel account and deploy immediately.

## 💎 Features

- **Avant-Garde Typography Engine**: Real-time switching between 7 fonts (Syncopate, Unbounded, Outfit, Space Grotesk, Bodoni Moda, Bebas Neue, Cinzel) with instant live preview.
- **Architectural PDP (Product Detail Page)**: High-resolution zoom gallery, true-to-silhouette boxy sizing guide, zero-bacon collar callouts, and verified customer dossiers.
- **Shoppable Cinematic Video Reels**: Full-screen modal video player with direct "Shop the Look" integration.
- **Slide-Out Minimalist Shopping Bag**: Free express shipping progress bar, quantity adjustments, and multi-currency conversion (INR ₹, USD $, EUR €, GBP £).
- **SEO & Social Share Ready**: Complete OpenGraph, Twitter card metadata, semantic schema, `robots.txt`, and `sitemap.xml`.
- **Ultra-Fast CDN Caching**: `vercel.json` configured with 1-year immutable caching on static assets and instant edge delivery.
